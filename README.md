# Omnifood — Goodbye Junk Food. Hello Super Healthy Meals.

A responsive food delivery service landing page built with **HTML** and **CSS**, using a float-based grid system and scroll-triggered animations via jQuery.

## Overview

Omnifood is a fictional premium meal delivery platform. The project focuses on building a polished, multi-section marketing page with a custom responsive grid, entrance animations, smooth scrolling, and a sticky navigation bar — all without a CSS framework like Bootstrap.

## Sections

- **Header** — Full-screen hero with two call-to-action buttons and a sticky navigation bar
- **Features** — Four-column grid highlighting key selling points (365 days/year, 20-minute delivery, 100% organic, unlimited choices)
- **Meal Showcase** — Full-width image grid of 8 featured meals
- **How It Works** — Three-step process illustrated alongside an app mockup, with App Store and Play Store download buttons
- **Our Cities** — Available in Lisbon, San Francisco, Berlin, and London, with eater counts and chef stats
- **Testimonials** — Three customer quotes in a three-column layout
- **Pricing Plans** — Three subscription tiers: Starter ($19/meal), Pro ($149/month), and Premium ($399/month)
- **Contact Form** — Full contact form with name, email, a "how did you find us?" dropdown, newsletter checkbox, and message textarea
- **Footer** — Navigation links and social media icons (Facebook, Twitter, Google+, Instagram)

## Tech Stack

- HTML5
- CSS3
- jQuery (scroll effects, sticky nav, waypoints)
- jQuery Waypoints (scroll-triggered animations)
- Ionicons (icon font)
- Animate.css (entrance animations)
- Normalize.css
- Google Fonts — *Lato*

## Key CSS Concepts Practised

- Custom float-based responsive grid system
- Sticky navigation bar on scroll (jQuery)
- Scroll-triggered section entrance animations with Waypoints
- Smooth scrolling to anchor sections
- Responsive design with a dedicated `queries.css` media query file
- Mobile navigation toggle
- CSS transitions and hover effects
